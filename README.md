# Замер скорости скачивания

Скрипт 10 раз подряд скачивает ресурс по заданному URL. Каждый следующий запрос начинается после полного чтения предыдущего ответа. Данные читаются порциями и не сохраняются на диск.

## Запуск

Нужен Python 3.9 или новее. Сторонние пакеты не требуются.

```sh
git clone https://github.com/PapaSvin/download-speed-test.git
cd download-speed-test
python download_speed.py "octodex.github.com/images/original.png"
```

Для замера подставьте прямую ссылку на большой файл, например на изображение. Если протокол не указан, скрипт использует HTTPS. Для сервера, который поддерживает только HTTP, укажите `http://` явно.

Если `python` недоступен, используйте `python3` на macOS/Linux или `py` на Windows.

## Результат

- **Среднее время запроса (с)** — суммарное время десяти скачиваний, делённое на 10. Время каждого запроса измеряется от его начала до чтения всего тела ответа, включая ожидание первых данных и возможные перенаправления.
- **Скачано всего (байт)** — сумма размеров тел ответов, без HTTP-заголовков.
- **Скорость скачивания (Мбит/с)** — `скачанные байты × 8 / суммарное время в секундах / 1 000 000`. Один Мбит/с равен миллиону бит в секунду. Скорость относится к выбранному серверу и зависит от размера ресурса.

При ошибке HTTP или сети скрипт выводит номер запроса и завершается с кодом 1. Тайм-аут отдельной сетевой операции — 30 секунд.
